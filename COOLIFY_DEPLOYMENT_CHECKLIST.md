# Coolify Deployment Checklist for OmnixStorage

## Pre-Deployment ✅

- [ ] Have Coolify account/instance ready
- [ ] Know your domain (e.g., demo.omnixstorage.kegeosapps.com)
- [ ] Have GitHub repo connected to Coolify
- [ ] SSL certificate will be auto-generated by Coolify

---

## Coolify Configuration Steps

### 1. **Create Application in Coolify**
- [ ] Dashboard > Applications > New Application
- [ ] Connect to GitHub repo: `kabuchanga/kegoes-omnixstorage`
- [ ] Select branch: `main`
- [ ] Create application

### 2. **Configure Domain (SSL Setup)**
- [ ] Application > Settings > Domain
- [ ] Add domain: `demo.omnixstorage.kegeosapps.com`
- [ ] Enable SSL (Let's Encrypt, auto-generated)
- [ ] Save

### 3. **Configure Environment Variables** ⚠️ IMPORTANT
- [ ] Application > Settings > General > Environment Variables
- [ ] Add the following variables:

| Variable | Value | Notes |
|----------|-------|-------|
| `OMNIX_TAG` | `omnixstorage` | Docker image tag |
| `OMNIX_ADMIN_USER` | `admin` | Console username |
| `OMNIX_ADMIN_PASSWORD` | `change-me-in-production` | **Change this!** |
| `OMNIX_S3_ACCESS_KEY` | `admin` | S3 API access key |
| `OMNIX_S3_SECRET_KEY` | `change-me-in-production` | **Change this!** |
| `OMNIX_CONSOLE_API_URL` | `https://demo.omnixstorage.kegeosapps.com:9000` | **Must include :9000** |

### 4. **Configure Exposed Ports** ⚠️ CRITICAL
- [ ] Application > Settings > Ports/Expose
- [ ] **Remove any existing port mappings**
- [ ] **Add TWO ports:**

**Port 1 - Console UI:**
- [ ] Internal Port: `3001`
- [ ] Public Port: `3001`
- [ ] Service: `omnix-console`

**Port 2 - Storage API:**
- [ ] Internal Port: `5000` (maps to omnix-node1)
- [ ] Public Port: `9000`
- [ ] Service: `omnix-node1`

**IMPORTANT:** You MUST expose both ports for console ↔ API communication!

### 5. **Review Docker Compose**
- [ ] Application > Settings > Docker Compose
- [ ] Verify file is from our GitHub repo
- [ ] Should show `docker-compose.yaml` is configured
- [ ] No need to edit - repo handles it

### 6. **Configure SSL**
- [ ] Application > Settings > SSL
- [ ] Should show:
  - [x] Status: "Let's Encrypt (Auto-renewal enabled)"
  - [x] Certificate: For domain `demo.omnixstorage.kegeosapps.com`
  - [x] Auto-renewal: ✓ Enabled

### 7. **Deploy Application**
- [ ] Application > Deployments
- [ ] Click **Deploy** or **Redeploy**
- [ ] Wait 2-3 minutes for containers to start
- [ ] All containers should show **running** status:
  - [ ] omnix-etcd (running)
  - [ ] omnix-node1 (running)
  - [ ] omnix-console (running)

### 8. **Post-Deployment Tests**
- [ ] Test Console UI: `https://demo.omnixstorage.kegeosapps.com:3001/`
  - Expected: ✓ Page loads without SSL warnings
  
- [ ] Test API Health: `https://demo.omnixstorage.kegeosapps.com:9000/health`
  - Expected: ✓ Returns 200 with JSON response
  
- [ ] Browser DevTools (F12 > Network tab)
  - Expected: ✓ API requests to port 9000, no 404 errors
  
- [ ] Try creating a bucket in console UI
  - Expected: ✓ Bucket is created successfully

## Troubleshooting

### "No Available Server" Error
**Problem:** Console can't reach API
**Solution:** 
1. Verify port 9000 is exposed in Coolify
2. Check OMNIX_CONSOLE_API_URL includes `:9000`
3. Redeploy

See: `COOLIFY_REVERSE_PROXY_FIX.md`

### Certificate Errors
**Problem:** SSL certificate not valid
**Solution:**
1. Go to Application > Settings > SSL
2. Click "Regenerate Certificate"
3. Wait 1-2 minutes
4. Restart application

### Containers Keep Restarting
**Problem:** Containers won't stay running
**Solution:**
1. View logs: Application > Deployments > View Logs
2. Check for memory/CPU issues
3. Increase resource limits if needed

See: `COOLIFY_NO_SERVER_FIX.md`

### Can't Connect to S3
**Problem:** S3 credentials not working
**Solution:**
1. Verify S3 credentials in Environment Variables:
   - `OMNIX_S3_ACCESS_KEY`
   - `OMNIX_S3_SECRET_KEY`
2. Use console UI to verify storage is accessible
3. Restart omnix-node1 container
